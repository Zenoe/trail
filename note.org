* sign
1. 打开项目 C:\Users\2004l\source\android\trail
2. 点击 Build → Generate Signed Bundle / APK
3. 选 APK
4. 点 Create new… 创建密钥库
5. 选择保存位置，例如 C:\Users\2004l\keystore\trail-release.jks
6. 填写密钥库密码、Key alias（如 trail）、Key password，并设置有效期
7. 选择 release，完成生成
已签名 APK 会在：
app\build\outputs\apk\release\
密钥库 .jks 和两组密码必须长期保存；以后发布更新必须用同一套签名。不要把 .jks 或密码提交到 Git。
