# 0.3.1 定位体验修整

## 0.4.1-beta 更新（2026-10-11）

下文的“两帧稳定才显示预览、30 秒后隐藏、GPS 航向优先”为旧行为。当前地图预览使用 GPS、系统 NETWORK_PROVIDER 与最近 5 分钟缓存；首个有效位置即可显示，精度大于 50 米显示“大致位置”，超过 30 秒显示“最近位置”。新鲜精确 GPS 优先于粗略网络回调；超过 5 分钟隐藏。缓存按单调时间验证，不使用重启前的过期位置。罗盘独立启动，优先作为手机指向；旋转矢量传感器不可用时尝试地磁旋转矢量。地图旋转角从显示箭头中扣除。

前台网络位置仅供预览，永不进入录制服务；记录起点和速度异常过滤保持原规则。仅大致位置授权也可浏览当前位置，精确定位仍是记录条件。没有系统网络定位提供器或没有返回位置时，不能保证室内显示；不声称已接入六只脚使用的定位服务。此次 Debug 构建、JVM 测试和 Lint 通过；未运行新的模拟器或真机室内/传感器实测。

2026-10-11。前台地图独立订阅 GPS，不因尚未录制、暂停或结束而隐藏当前位置；切到后台后停止这份预览订阅，录制服务仍按原流程运行。首次打开需精确定位权限；拒绝后仍可浏览、导入已有轨迹，但无法显示自己的位置。

冷启动位置先等待两个精度不差于 25 米、相距合理的 GPS 样本，避免第一帧漂移。录制新分段同样等待稳定点；超出活动速度容差的跳点留在本机数据库并标记 `accepted=false`，不计距离、不画入路线。录制 GPX 导出仅包含通过质量检查的点，并在拒收区间断开 GPX 分段，避免第三方阅读器重新连出瞬移线；导入文件的 GPX 往返不受影响。过滤只决定点是否参与轨迹，不改写 WGS84 原始坐标。

蓝色位置标记在有移动航向时使用 GPS bearing；静止时若有旋转矢量传感器，则以设备罗盘方向和当地磁偏角显示箭头。无可靠方向时仅显示圆点，不猜测朝向。地图上的定位图标可将视角移回当前位置；查看远处导入路线时不会自动把路线缩到全球范围。超过 30 秒没有新定位则暂时隐藏当前位置；旧轨迹仍可查看。罗盘受磁干扰、GPS 受遮挡都会影响结果，不能作为安全导航或海拔校准。

验证：17 项 JVM 测试、25 项本地模拟器测试通过，Debug APK 构建成功；Lint 无错误、11 项警告。模拟器的 System UI 在截图检查时出现无响应，因此本轮未完成可靠的人工视觉验收。未安装到手机；真机、户外和多种传感器设备尚未实测，模拟器无法充分代表真实冷启动抖动与磁环境。
