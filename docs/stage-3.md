# 阶段 3：轨迹管理与 GPX 导出

版本 0.3.0，2026-10-09。

## 使用

在「轨迹」页可按名称搜索，按全部、记录、导入、路线筛选。进入详情可重命名或确认删除当前路径；含多条路线的文件仅删除所选路径。仍在记录中的轨迹要先结束才能删除或导出。

详情页「导出 GPX」或「分享」可选择当前路径或整个文件，以及是否包含顶层标记。导出先生成并校验本机 GPX 1.1，再通过系统文件选择器指定保存位置；取消选择器不提示成功。导入文件另有「分享导入原文件」，与语义导出分开，原件保持导入时的字节内容。分享使用系统分享界面和只读临时授权。

## 数据保证

- 导出使用数据库中所有原始点，不取地图抽稀结果；保留 WGS84 坐标、点序、分段、路线/轨迹类型、可空时间与海拔、航点和已保存的命名空间扩展。
- GPX 1.1 要求根节点的路线在轨迹之前，因此混合文件导出时跨类型顺序可能变化；同类内部仍按导入顺序。路径重命名进入语义导出，原文件分享不变。
- GPX 1.0 的 URL 和作者字段按可映射部分转换为 1.1 link/person，其余旧字段放入带版本信息的应用扩展。转换后的实例见 [1.0 转换样本](stage3-one-zero-converted.gpx)。
- 数据库继续使用 v2，现有记录无需重新导入。删除路径时外键级联删除分段与点，并清理对应扩展；只有最后一个对象删除后才清理原始文件副本。

## 验证

使用 JDK 17、SDK 36、Gradle 8.13：

```powershell
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug
```

设备侧使用本地 Android 37 模拟器，未安装到手机。16 项 JVM 测试、21 项模拟器测试通过，Lint 为 0 错误、9 条警告。测试涵盖多轨迹/路线/航点往返、缺失值和未知扩展、1.0 转 1.1、只导出所选路径、分享文件授权、保存失败清理、活跃录制保护、改名筛选与删除。实际导出的 [GPX 1.1 样本](stage3-roundtrip.gpx)和 [1.0 转换样本](stage3-one-zero-converted.gpx)均经 TopoGrafix [官方 GPX 1.1 XSD](https://www.topografix.com/GPX/1/1/gpx.xsd)独立校验通过。
