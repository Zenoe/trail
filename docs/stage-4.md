# 阶段 4 工程预览（0.4.0-beta）

0.4.5-beta：空闲地图的开始/导入并列并贴近底栏，地图改为弹性高度；详情移除重命名按钮，同样让地图获取更多空间。统计区独立滚动并给地图预留至少约 220dp，避免小屏或长 GPX 标记列表把地图完全挤掉。记录中页面保持既有全屏地图与底部暂停/结束操作。

0.4.4-beta 界面收紧：去除地图、列表、详情的顶部标题栏；设置移至底栏最右侧，录制中也可进入。地图状态文字不再占地图下方，操作按钮移入地图；OSM 署名仍在地图内。详情删除靠近分享且保留确认；列表搜索框改为 44dp 高，右侧直接导入 GPX。系统返回手势、底栏切页和全屏退出继续提供返回路径。

0.4.2-beta 增加累计上升/下降：记录顶栏使用紧凑的 ↑/↓ 与动态 m/km 单位，详情展示对应统计。录制增量计算、导入解析和 v3 数据库迁移回填共用 5 米高程死区算法；连续海拔不足两个时显示 —，断点不连接计算，原始海拔仍保留。GPS 高程未校正，结果是估算。Debug 构建成功，24 项 JVM 测试、21 项定向模拟器测试通过，Lint 0 错误、11 项警告；未安装手机或进行户外高程验收。

2026-10-11。阶段 4 原定范围为离线区域、质量过滤、省电调优和多厂商恢复。本版只交付无需外部地图授权、且能在本地验证的部分，不把阶段 4 的全部验收条件视为达成。

- 定位质量：沿用 0.3.1 的稳定起点、速度异常跳点过滤、原始坐标保留及 GPX 安全导出。详见 [定位体验修整](location-polish.md)。
- 省电基础：同一进程的前台位置预览与录制服务共享一份平台 GPS 订阅；暂停且退出前台时停止订阅。录制写入仍只经过服务与仓库，预览不会创建轨迹点。尚未通过电流/电量仪器验证实际节电幅度。
- 长轨迹显示：地图查询按总点数抽稀；连续拒收样本仅保留首个断线哨兵，并保留恢复后的首个有效点和各段端点。原始点与 GPX 导入/导出不抽稀。结果规模约为一万采样点，加分段与质量断点数量；极端频繁断点仍可能超过该数。尚未达到“10 万点预览 <3 秒”的实测验收。
- 中断恢复：仍保持进程启动一次恢复、前台服务 `START_NOT_STICKY`、由用户明确继续并创建新段；本轮没有扩大为自动后台重启。

未实现：离线区域下载与离线包配额/完整性检查，因为当前没有允许离线下载的授权地图服务；公共 OSM 在线瓦片只用于用户主动开启的在线浏览，不用作批量离线源。待提供合法地图样式/密钥及离线授权后，再设计下载区域、配额、清理和断点续传。

未验收：中端真机 2–4 小时锁屏耗电、弱网/飞行模式/重启/存储不足演练、多厂商后台限制、真实冷启动定位抖动与磁罗盘、10 万点性能目标。模拟器功能测试不能代替这些结果；仍不安装到手机。

本地验证：Debug APK 构建成功；18 项 JVM 测试与 26 项 Android 37 模拟器测试全部通过，Lint 0 错误、11 项警告。测试包括 GPS 订阅共享、连续拒收段的地图断线、录制中断/恢复和现有 GPX 往返。模拟器曾出现偶发定位回调延迟，测试通过重复注入邻近样本等待状态推进；这不是户外定位精度证明。

0.4.1 后续交互：当前位置的新样本用实时单调时钟验证，避免被每秒 UI 计时器的旧值误判为未来而闪烁。「结束」打开含「保存」「放弃」的底部菜单；点击放弃通过服务串行命令和数据库事务删除当前会话，携带路径 ID，迟到命令不能删除下一次记录。关闭菜单保持当前状态。

本轮验证：Debug 构建、20 项 JVM 测试、Lint 通过；11 项定向模拟器测试通过，覆盖保存/放弃界面、录制状态与删除后的迟到样本保护。未安装到手机，尚未真机观察位置图标。
