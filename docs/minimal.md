# 极简无地图引擎版（0.4.4-minimal）

分支：`minimal-no-map-engine`。此版本只有轨迹视图，没有地理底图。保留记录、暂停/恢复、累计距离与升降、GPX 导入导出、参考路线、航点、当前位置和朝向。轨迹可拖动、双指缩放，也有放大、缩小、全程和回到当前位置按钮；全屏地图仍可用。空白背景不表示真实道路、坡度或可通行性，不能当作导航底图。

构建中不再包含 MapLibre、高德 SDK、OkHttp 地图缓存、地图选择偏好与高德 Key 注入。Manifest 不申请 INTERNET 权限。开发者机器原有 `local.properties` 的高德 Key 没有删除，因为该本机文件被 Git 忽略、由其他分支复用；极简分支构建脚本不读取或打包它。应用 ID、Room 数据库结构、WGS84 原始坐标和 GPX 契约不变，原应用数据可继续读取。

Canvas 渲染保持 GPX 分段与拒收点的断线边界；跨日期线按短弧显示。等距近似适合常见步行/骑行小范围轨迹，并非地图投影；跨大区域、高纬度路线的画布距离和形状不能用于测量。距离统计仍由原始坐标计算，不取画布像素。纯色底下当前位置与轨迹的相对形状可见，但没有地点名称或道路。

验证：debug APK 构建成功，26 项 JVM 单元测试通过；Lint 0 错误、8 警告。Android 37 模拟器的 GPX 导入、保存及加载参考路线定向测试通过。尚未对 Canvas 手势做触控实测，也未安装到手机或进行户外定位、长时间锁屏实测。
