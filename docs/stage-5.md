# 阶段 5：可访问性、隐私与签名内测

## 本版实现

- 首次申请当前位置前说明用途，可选“暂不定位”；不妨碍本地轨迹浏览和 GPX 导入。设置内可随时查看隐私与数据说明、管理系统权限、撤销高德地图同意。
- 地图图标有可点击的按钮语义和 52 dp 命中区。列表左滑删除保留，同时提供无障碍自定义“删除轨迹”操作。导入选择项按复选框朗读和操作。
- 字体放大时，首页操作、轨迹搜索/导入和详情操作改为纵向布局；筛选可横向滚动，列表名称与摘要可换行。
- 内测版从本机 `local.properties` 读取已有密钥配置签名；口令不得写入 Git 或文档。`trail-release.jks` 目前已在 Git 历史中，**不应把它视为安全的正式发布密钥**。正式发布前应更换密钥、核对高德 SHA-1，并处理历史泄露风险。

## 数据与网络边界

定位预览不写入轨迹，点击开始记录后才保存。空白底图不加载瓦片；OpenStreetMap 和高德底图需联网。应用不自动上传 GPX，导出/分享由用户选择目标。卸载或清除数据会删除本机私有数据，请定期导出备份。

## 验收记录

2026-10-13 工程实测：`assembleRelease`、`assembleDebug`、`testDebugUnitTest`、`assembleAndroidTest` 均通过；新增无障碍 UI 测试在 API 37 模拟器默认及 200% 字体下通过。默认字体的地图选择、GPX 导入、轨迹管理 3 项 UI 回归测试通过；200% 字体的录制、GPX 导入、轨迹管理 4 项测试通过。这是自动化可操作性验证，不替代人工视觉与 TalkBack 检查。签名 release APK 的证书 SHA-1 为 `1F:CA:57:A0:A4:EF:6D:6B:2A:9A:4A:EE:F7:A4:14:AD:23:82:6F:40`，与登记值相同，APK 为 85.6 MiB；显著高于单 ABI 35 MiB 的轻量目标。

Redmi Note 8 Pro / Android 9 已使用 debug 签名包保留数据升级到 0.5.0-beta，启动后进程保持运行。ADB 单次启动报告 `ThisTime=2448 ms`，前台一次 `dumpsys meminfo` 为 72,970 KiB PSS；这不是标准化冷启动或长时间性能试验。手机既有版本使用 debug 签名，与 release 签名不兼容，系统拒绝保留数据升级 release 包；未卸载或清除用户数据。

已目视检查模拟器 200% 字体的首页、详情和列表截图，主要按钮和文本无明显裁切；详情操作位于可滚动区域下方。TalkBack 仍需真人检查焦点顺序、按钮朗读、删除自定义操作和对话框；10 万点预览与 2–4 小时锁屏耗电尚未实测。长时路测需记录设备型号、OS、温度、电池健康、网络、屏幕状态和电量变化。未实测的指标不视为通过。
