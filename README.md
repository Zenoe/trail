# 山径 · 轻量 Android 轨迹工具

2026-10-11。暂定名「山径」，面向 Android 的轻量轨迹记录与加载工具。

0.4.2-beta：记录顶栏在距离旁显示累计上升/下降（↑/↓），数值按大小显示米或公里，控制小数位；详情页显示对应累计量。实时记录、GPX 导入与已有轨迹使用同一 5 米高程死区算法。结果为未校正海拔的估算，缺失/拒收样本及分段不跨越累计；原始海拔不变。

阶段 0 交付：产品边界、竞品启发、界面与交互规格、可点击原型、GPX 优先的数据契约、权限/耗电/地图方案及后续验收清单。

阶段 3（0.3.0）已实现：轨迹搜索、来源与路线筛选、重命名和确认删除；选择路线或整个文档导出 GPX 1.1，通过系统文件选择器保存或分享，还可单独分享导入原文件。沿用阶段 2 的 GPX 流式导入、独立参考路线与阶段 1 的 GPS 记录。默认离线轨迹视图无底图，可在设置中自愿开启 OpenStreetMap 在线浏览；不含离线地图下载。

2026-10-10 交互修整：地图可全屏，提供明确的放大、缩小和全程按钮；暂停或中断的当前记录可确认丢弃；轨迹列表左滑可露出删除按钮。在线底图直接显示 OpenStreetMap 署名，不再显示容易误触的 MapLibre 信息点。

后续界面微调：全屏地图改用半透明图标按钮，顶部显示当前位置的经纬度与海拔（未定位或缺失时显示“—”）；列表收为两行卡片，左滑仅露出红色「删除」按钮，点击后直接删除，详情页仍保留确认框。

0.3.1 定位体验修整：前台地图在未开始、暂停或结束录制时也可显示当前位置；移动时用 GPS 航向箭头，静止时有设备罗盘则显示朝向。录制起点等待两次邻近定位，瞬移点不连线、不计距离；录制 GPX 导出跳过拒收点，导入文件继续逐点往返。首次显示位置需精确定位权限，拒绝后仍可浏览轨迹。

0.3.2 界面调整：底部导航改为纯文字；录制中以距离、有效时间、经纬度与海拔组成紧凑顶栏，地图占满其余空间，底部仅保留轨迹、暂停/继续和结束保存。地图保留方向箭头、定位、全程和缩放控件；列表、详情与设置的间距也收紧。

阶段 4 工程预览（0.4.0-beta）：前台定位与录制服务共享一份 GPS 系统订阅；长轨迹地图预览压缩连续拒收点，同时保留断线边界和恢复后的首点。冷启动/瞬移质量过滤沿用 0.3.1。你目前没有获准离线下载的地图源，所以本版不提供离线底图包；也未完成 2–4 小时真机锁屏路测与多厂商恢复验收。

0.4.1-beta 室内位置修正：地图预览增加系统网络定位和 5 分钟内的位置缓存，允许大致位置，超过 30 秒标注“最近位置”；录制继续只使用共享 GPS 和严格质量过滤。手机罗盘方向优先于移动航向，旋转地图后箭头仍按正确方向显示。支持仅授予大致位置权限时预览；记录仍需精确位置权限。室内效果依赖设备提供的网络定位与方向传感器，尚未真机验证。

同版交互修整：修复定位回调与每秒 UI 时钟不同步导致的当前位置闪烁；记录底部改为「结束」，点击弹出「保存」「放弃」。保存进入详情，放弃删除本次记录；关闭菜单则继续原有记录状态。
